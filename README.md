# 📝 ToDo List App

A simple and responsive ToDo List web application built with **HTML**, **CSS**, and **JavaScript**. The application allows users to manage tasks by adding todos, assigning due dates, and removing completed tasks through a clean and responsive interface.

##  Live Demo

🔗 https://to-do-list-drab-phi-89.vercel.app

##  Features

- Add new tasks
- Set a due date for each task
- Delete completed tasks
- Responsive layout for desktop and mobile devices
- Clean and minimal user interface
